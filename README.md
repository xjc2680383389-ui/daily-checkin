# 每日打卡 📅

一个精美的桌面日历打卡应用，用 Python + CustomTkinter 构建，可打包为独立 exe 运行。

## ✨ 功能

- **日历网格** — 类传统日历的月视图，一目了然
- **一键打卡** — 点击日期即可标记打卡，再点取消
- **数据持久化** — 自动保存到本地 JSON 文件，永不丢失
- **统计面板** — 🔥连续打卡 / 📅本月打卡 / 🏆总计打卡
- **月份导航** — 自由切换任意月份，支持补卡
- **今日高亮** — 蓝色边框标示今天，绿色标示已打卡
- **独立运行** — 可打包为单个 exe，无需 Python 环境

## 🚀 快速开始

### 方式一：直接运行 exe（推荐）

下载 `dist/每日打卡.exe`，双击即可运行。

### 方式二：Python 源码

```bash
pip install customtkinter
python checkin.py
```

或双击 `启动打卡.bat`

### 方式三：自行打包

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 每日打卡 checkin.py
```
