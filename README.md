# 每日打卡 📅

一个精美的桌面日历打卡应用，用 Python + CustomTkinter 构建，可打包为独立 exe 运行。

## ✨ 功能

- **日历网格** — 类传统日历的月视图，一目了然
- **一键打卡** — 点击日期即可标记打卡，再点取消
- **数据持久化** — 自动保存到本地 JSON 文件，写入完成后原子替换；请定期备份
- **统计面板** — 🔥连续打卡 / 📅本月打卡 / 🏆总计打卡
- **月份导航** — 自由切换任意月份，支持补卡
- **今日高亮** — 蓝色边框标示今天，绿色标示已打卡
- **独立运行** — 可打包为单个 exe，无需 Python 环境

## 🚀 快速开始

### 方式一：运行自行打包的 exe

当前仓库不附带 exe 下载文件。按下方步骤自行打包后，可双击 `dist/每日打卡.exe` 运行。

### 方式二：Python 源码

```bash
python -m pip install -r requirements.txt
python checkin.py
```

或双击 `启动打卡.bat`

### 方式三：自行打包

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 每日打卡 checkin.py
```

## 数据与检查

数据位于用户目录的 `.daily-checkin/checkins.json`。保存失败或数据损坏会显示错误并保留原文件，不会自动清空记录；多个窗口打卡时会在文件锁内读取最新记录再保存。旁边的 `.lock` 是协调文件，请勿在应用运行时删除。跨午夜时会自动更新今天日期。

运行回归检查：`python -m unittest -v`。界面测试需要可用的桌面显示环境，且使用临时数据目录，不修改个人打卡记录。
